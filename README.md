# Wild Frontier

A wildlife rescue and conservation simulation with a handcrafted, claymation-inspired 3D art direction.

## Current slice
- Full-viewport, real-time 3D woodland scene (Three.js)
- Sculpted terrain, layered foliage, creek, field station and miniature environmental details
- Custom modeled deer and rabbits with subtle idle animation
- Orbit camera (drag), zoom (wheel/pinch-ready), keyboard movement (WASD / arrows)
- Clickable wildlife observations and contextual field tools
- Compact in-world HUD rather than a long, stacked landing page
- Responsive desktop and mobile layouts

## Run locally
```bash
npm install
npm run dev
```

## Art direction
The goal is a tactile miniature world: soft forms, imperfect silhouettes, warm directional light, matte materials, layered depth and individually composed environments. Kenney-style simplicity is a useful modelling reference, not the final visual identity.
